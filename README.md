# Rat-Attack
All Rat Attack Scripts. 08-21-2023. The Folder "Lobby" contains all scripts used in the Pre-Game Lobby where players can join games with other players. The Folder "VKALabs" contains all scripts used in the actual game level VKA Labs.

Note: Most Core Server System Scripts are located in "ServerScriptService" in the "VKALabs" Folder. Core Local Client Scripts are located in the "StarterCharacterScripts" Folder of "VKALabs" Folder.
